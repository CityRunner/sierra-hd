# ScummVM patches

Patches applied to the pinned ScummVM revision by
`tools/reference-scummvm/build.sh`, in name order. Each file is a `git diff`
against that revision, named `NNNN-short-description.patch`, and starts with
a comment saying what it adds and which milestone needs it (buffer dumps,
kernel-call traces, the deterministic mode with a fixed seed, virtual clock
and replayed input).

There are no patches yet (milestone 0).
