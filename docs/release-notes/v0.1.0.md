First release: the room viewer (milestones 3a and 3b). It is not yet the game.

- Every background picture of The Colonel's Bequest in HD (vector) or
  original mode, at any whole-number scale, with the priority map.
- Every view with its animation, and every font.
- HD backgrounds use the scene-analysis hints in `hints/`.
- The game folder is identified by its file hashes; the English DOS 3.5"
  release is tested, the 5.25" release is accepted with a warning.

Binaries for Linux (glibc 2.38 or newer) and Windows, x64 and ARM64.
Bring your own copy of the game; see README.md in the archive.
