# Scenario recordings

Replays (docs/formats/replay-and-trace.md) that are run in the reference
ScummVM and in sci-vm and must give the same kernel-call trace, screens,
1x priority and control maps, actor positions and parser results:

    SIERRA_HD_MOUNTS=/path/to/game:/game docker/run.sh \
        tools/vm-trace/run-scenario.sh tests/scenarios/<name>.txt <stop tick> build/scenarios/<name>

`scenarios.txt` lists every run with its stop tick and seed;
`tools/vm-trace/run-all-scenarios.sh` runs them all. The table lists the
recordings made by hand; all use seed 0.

| Scenario | Stop tick | What it covers |
| --- | --- | --- |

## The parser corpus (milestone 6a)

`parser-forms*.txt` and `parser-words-*.txt` are generated by
`tools/vm-trace/make-parser-scenarios.py` from the game's vocabulary (as
`sci-vm-trace --vocabulary` reads it through sci-text); do not edit them by
hand, change the generator and run it again. Each walks Laura into a room
along the route of an earlier recording, then types commands, each closed
with Enter and a second Enter (Escape for quit, restart, save and restore,
whose questions would otherwise take the default button). Together they
type all 1295 words of vocab.000 at least once, in a sentence for the
word's class.
